# Fahim Faysal | Portfolio

A modern personal portfolio website built with React and Vite to showcase my professional background, projects, education, experience, skills, and references.

## Overview

This portfolio is designed to present my work in a clean, responsive, and professional way. It highlights:

- About me section
- Education and experience
- Technical skills
- Featured projects
- Personal pictures and references
- Contact information

## Tech Stack

- React
- Vite
- CSS Modules
- JSON-based content structure

## Features

- Responsive design for desktop and mobile
- Smooth single-page portfolio layout
- Dynamic content from local JSON data
- Clean UI with modular component structure
- Easy to customize for personal branding

## Project Structure

- src/pages/ - Main page sections such as Hero, About, Education, Experience, Skills, Portfolio, References, and Footer
- src/database/ - Portfolio content stored in JSON files
- src/assets/ - Images, PDFs, and other media assets

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open your browser and visit:

```bash
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Deployment

This project is ready to be deployed on Netlify or any other static hosting platform.

### Netlify deployment settings

- Build command: `npm run build`
- Publish directory: `dist`

## GitHub

You can push this project to GitHub and connect the repository to Netlify for automatic deployment.
